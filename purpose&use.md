# CoinRex Purpose & Use Guide

This document explains CoinRex in simple language so it can be shared with:

- friends
- developers
- AI tools/models
- testers
- product reviewers

The goal is to collect feedback about what CoinRex is, what it should communicate, and what should appear on the homepage so first-time visitors understand it quickly.

---

## 1. Who We Are

CoinRex is a platform built around **crypto project reviews, public trust, and user rewards**.

It is designed for two main groups:

1. **Users / Reviewers**
   - people who use crypto projects
   - people who want to share their experience
   - people who want to earn rewards for useful reviews

2. **Developers / Project Owners**
   - people building crypto projects
   - teams who want to list their project
   - teams who want to build public credibility and trust

So in very simple words:

> CoinRex is a place where users review crypto projects and projects build public trust.

---

## 2. What CoinRex Does

CoinRex helps create a public system where:

- users can submit reviews about crypto projects
- those reviews can be moderated and approved
- projects can receive visible public feedback
- trust is built through review activity, proof, and transparency
- users can earn platform rewards for valuable contributions

It is not just a blog.
It is not just a listing website.
It is not just a reward app.

It combines:

- **project discovery**
- **review submission**
- **proof-backed trust signals**
- **reward earning**
- **task-based user progression**

---

## 3. CoinRex Purpose

The main purpose of CoinRex is to solve a common crypto problem:

### Problem
In crypto, many people often do not know:

- which project is real
- which project is active
- which project users actually like
- which project only has hype/marketing
- where they can find real user feedback

### CoinRex Purpose
CoinRex tries to solve that by creating a system where:

- users can share real experiences
- projects can be reviewed publicly
- trust becomes more visible
- rewards encourage user participation
- moderation improves content quality

In short:

> CoinRex exists to make crypto project trust more public, more review-driven, and more useful for both users and builders.

---

## 4. What Users Can Do on CoinRex

Users/reviewers can use CoinRex to:

### A. Create an account
- sign up
- verify identity/email/OTP where required
- join the platform as a participant

### B. Explore crypto projects
- browse available listed projects
- see project details
- check trust-related activity
- see public review information

### C. Submit reviews
- share their real experience about a project
- explain what they liked or disliked
- contribute public review content

### D. Submit proof
- provide supporting evidence when required
- help make reviews more credible
- contribute proof-backed trust signals

### E. Earn rewards
- earn $REX or platform rewards for approved contributions
- benefit from useful participation

### F. Grow inside the platform
- move through user levels like Beginner / Pro / Expert
- complete tasks or progression steps
- build a stronger platform profile

### G. Participate in extra systems
Depending on the platform flow, users may also interact with:

- **TaskHub**
- **BoostHub**
- referrals
- reward history
- notifications

In simple words:

> A user comes to CoinRex to explore projects, write reviews, submit proof, earn rewards, and build a trusted reviewer profile.

---

## 5. What Developers / Project Owners Can Do on CoinRex

Developers and project owners can use CoinRex to:

### A. Create a project-side account
- register as a builder / project owner
- access the developer-side workflow

### B. Submit a project for listing
- add their project details
- request approval/moderation
- become visible on the platform

### C. Receive public reviews
- allow users to review the project
- collect visible feedback from real participants
- understand how users see the product

### D. Build trust
- use public reviews as a trust signal
- show that the project is real, active, and open to feedback

### E. Improve visibility
- benefit from stronger public presence
- use platform promotional layers where applicable
- grow attention without replacing trust-based signals

### F. Use project growth features
CoinRex also appears to support ideas like:

- featured/project visibility layers
- sponsored visibility layers
- priority handling layers

Important principle:

> visibility can be improved through platform features, but trust should still come from real user feedback and review quality.

In simple words:

> A developer comes to CoinRex to list a project, get reviewed publicly, and build trust with users.

## 6. How CoinRex Works

Here is a simple explanation of how the platform works.

### For Users
1. User joins CoinRex
2. User browses projects
3. User selects a project
4. User submits review + proof (if required)
5. Review goes through moderation/approval
6. Approved review becomes part of the trust ecosystem
7. User may receive rewards and progression benefits

### For Developers / Projects
1. Developer joins CoinRex
2. Developer submits project for listing
3. Project goes through approval/moderation
4. Project becomes visible on the platform
5. Users review the project
6. Reviews help shape public trust and visibility

### Core platform loop
The full platform loop is roughly:

**project listing → user review → moderation → public trust → reward / visibility growth**

## 8. What Should Be On the Homepage

The homepage should answer these 3 questions in the **first 5 seconds**:

1. **What is CoinRex?**
2. **Who is it for?**
3. **What should I do here?**

If the homepage fails to answer these, new visitors get confused.

### Minimum homepage message requirements
The homepage should clearly explain:

- CoinRex is a platform for crypto project reviews and trust
- Users can review projects and earn rewards
- Developers can list projects and build credibility
- Reviews/proof/moderation make the system useful

### Homepage should show 2 clear user paths
There should be a very clear split:

#### Path 1 — For Users / Reviewers
- sign up
- review projects
- submit proof
- earn rewards

#### Path 2 — For Developers / Projects
- list a project
- get public reviews
- build trust
- improve visibility

### Homepage should avoid too much confusion
If the first screen is too abstract, visitors may think:

- “yeh kya hai?”
- “mujhe yahan kya karna hai?”
- “yeh reward app hai ya review platform?”
- “yeh user ke liye hai ya developers ke liye?”

So the homepage should use simpler and more direct language.

---

## 9. What Homepage Sections Should Exist

Below is a recommended structure for a beginner-friendly homepage.

### 1. Hero Section
Should clearly say:

- CoinRex kya hai
- user kya kar sakta hai
- developer kya kar sakta hai
- 2 main CTA buttons

### 2. What is CoinRex?
A short section in plain words:

- who we are
- what we do
- why we exist

### 3. Choose Your Path
Two clear cards:

- I’m a User / Reviewer
- I’m a Developer / Project Owner

### 4. How It Works
Simple 3–4 step flow.

### 5. Trust / Live Activity / Proof
Show that the platform is real and active.

Examples:
- approved reviews
- projects
- active reviewers
- trust score

### 6. Real Reviews / Testimonials
Show examples of public review activity.

### 7. Blog / Learning Section
Useful only if it supports understanding, not distracts from it.

### 8. Final CTA
Again split clearly for:

- reviewers
- developers
